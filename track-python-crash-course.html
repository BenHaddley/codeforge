Python Crash Course

A companion quest track for Python Crash Course by Eric Matthes (No Starch Press). 11 fundamentals quests, one per chapter of Part I, plus 3 boss quests for the project arcs in Part II. Every prompt below is my own — read the actual chapter first, then use these to prove you've got it.

Level 1
0 / 0 XP

Part I — Fundamentals

Ch. 1 · Getting Started 20 XP

Hello, Forge

Get Python running and write a script that prints three lines about yourself, each using a different string on its own print() call.

Ch. 2 · Variables & Data Types 30 XP

Name Tag Generator

Store a first and last name in variables, then build three differently-formatted greetings (upper, title, and a custom f-string) without retyping the names.

Ch. 3 · Introducing Lists 30 XP

Inventory Roll Call

Build a list of five items. Print the first and last using indexing, add a new item, remove one by value, and reorder the rest alphabetically.

Ch. 4 · Working with Lists 40 XP

Loot Sorter

Generate a list of 20 random numbers with range(). Print the min, max, and sum, then produce a sorted copy without disturbing the original list.

Ch. 5 · if Statements 40 XP

Class Selector

Given three stat values (strength, agility, intellect), write branching logic that picks a character class, handling ties and out-of-range values gracefully.

Ch. 6 · Dictionaries 50 XP

Character Sheet

Model a game character as a dictionary with nested stats and a list of inventory items. Write a function that prints a formatted summary from it.

Ch. 7 · Input & while Loops 50 XP

Dungeon Prompt

Write an interactive loop that keeps asking for a command until the user types "quit", validating input and rejecting empty entries along the way.

Ch. 8 · Functions 60 XP

Spellbook

Turn three repeated snippets from earlier quests into functions with sensible default arguments, then write one function that accepts a variable number of arguments.

Ch. 9 · Classes 70 XP

Forge a Hero

Define a Character class with attributes and a take_damage() method, then a subclass that overrides one method to add unique behavior.

Ch. 10 · Files & Exceptions 70 XP

Save File

Save your character sheet to a JSON file and load it back on the next run. Handle a missing or corrupted save file without crashing.

Ch. 11 · Testing Your Code 60 XP

Prove It Works

Write unit tests for your take_damage() method and Class Selector logic, covering at least one edge case for each.

Part II — Boss Quests

Boss · Arcade Game 150 XP

Something That Moves

Build a small 2D game with a library like pygame: a player object that responds to keypresses, at least one hazard or enemy, and a visible score.

Boss · Data Visualization 150 XP

Make the Numbers Talk

Pull or generate a dataset and produce at least two different chart types (e.g. matplotlib or plotly) with labeled axes, plus a short written takeaway.

Boss · Web App 150 XP

Ship It Online

Build and deploy a minimal web app with one form, one dynamic page, and basic login/logout, using a framework of your choice.
