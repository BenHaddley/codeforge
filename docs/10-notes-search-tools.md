# 10 — Notes, Search and Tools

The toolbar in the reference image creates room for features that can make Code Forge more useful than a single course page.

## Notes

Each note should have:
- lesson ID;
- title;
- body;
- created/updated timestamps;
- optional code snapshot;
- optional tag.

Phase 1: IndexedDB/local browser.  
Phase 2: sync to account.

## Search

Index:
- lesson titles;
- explanation text;
- glossary terms;
- example titles;
- learner notes.

Results should open the exact lesson/section rather than just a track homepage.

## Tools menu

Start small:
- Python playground;
- JSON formatter;
- regex tester;
- Base64/text converter;
- timestamp converter.

Later:
- SQL playground;
- HTTP request builder;
- Git command explainer;
- subnet calculator for networking tracks.

Tools should be genuinely useful to a learner, not decorative toolbar filler.
